# dotfiles archive

過去に使っていた設定と、その管理方式の変遷を残すためのアーカイブ。

2026-08-26 に chezmoi による継続管理を終了した。現在のホームディレクトリへ
このリポジトリを自動適用することはなく、drift timer・fish greeting・自動コミットも
使用しない。

`home/` 以下は終了時点の設定スナップショットで、ファイル名には chezmoi の命名規則が
残っている。必要な設定を再利用するときは、履歴と内容を確認して個別に取り出す。

このリポジトリは public であるため、今後も秘密情報をコミットしない。
`.githooks/pre-push` の gitleaks ゲートは残している。
